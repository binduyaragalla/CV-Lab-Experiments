## Experiment 3: Average Filter

### Aim
To apply average filtering to a grayscale image using 3×3, 5×5 and 7×7 kernels and compare the smoothing effects.

### Libraries Used
- OpenCV
- NumPy
- Matplotlib

### Description
In this experiment, average filters of different kernel sizes are applied to an image using OpenCV. The results of 3×3, 5×5 and 7×7 filters are compared.
